HTTPS is the secure version of HTTP, the protocol browsers use to load websites. It relies on an SSL certificate, more precisely a TLS certificate today, to encrypt data between the visitor's browser and your server and to prove your site is genuine. Every website needs one: it protects form and login data, prevents "Not secure" browser warnings, builds trust, supports modern browser features and is a light Google ranking signal. Many hosts now provide free certificates.

What an SSL certificate does

  • Encryption: data in transit cannot be read by others on the network.
  • Integrity: pages cannot be altered on the way, for example by injected ads.
  • Authentication: visitors know they reached your real site.

For most businesses, a free DV certificate from Let's Encrypt or the host is enough; the encryption is the same strength.

How to set up HTTPS

  1. Get a certificate from your host, CDN or a certificate authority.
  2. Install it and enable automatic renewal.
  3. Redirect all HTTP URLs to HTTPS with 301 redirects.
  4. Update internal links, canonical tags and sitemaps to HTTPS.
  5. Fix mixed content: images, scripts and styles still loading over HTTP.
  6. Consider HSTS, which tells browsers to always use HTTPS.
  7. Update Search Console and analytics settings.

On WordPress, update the site address settings and run a search-and-replace for old HTTP URLs. On Shopify, SSL is included automatically.

How SSL affects SEO

Google confirmed HTTPS as a lightweight ranking signal, and it is part of page experience. More importantly, browsers mark HTTP pages as "Not secure", which drives visitors away and hurts conversions. During a move to HTTPS, correct 301 redirects keep your rankings intact. Google's guide to site moves with URL changes applies here.

What SSL costs

Free DV certificates cover most websites. Paid OV, EV or wildcard certificates cost more each year, depending on the provider. The real cost is usually setup time, such as fixing mixed content on an older site.

Common SSL mistakes

  • Letting a certificate expire, which shows a scary browser warning.
  • No redirect from HTTP, leaving duplicate versions of the site.
  • Mixed content that breaks the padlock or blocks scripts.
  • Redirect chains, such as HTTP to www to HTTPS in several hops.
  • Forgetting subdomains not covered by the certificate.

SSL is the start, not the end

An SSL certificate protects data in transit, but it does not stop malware, weak passwords or outdated plugins. Combine it with the wider steps in our guide to business website security.
