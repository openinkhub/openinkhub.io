Programmatic SEO is the creation of many pages from a template and a dataset, such as one page per city, product type or integration. It still works in the AI era, but only when each page offers something unique and useful. Pages that swap a keyword into the same text now risk falling under Google's scaled content abuse policy, and AI tools rarely cite them.

Where programmatic SEO still works

  • Real data per page: prices, specifications, timetables or statistics that differ for each item.
  • Genuine local detail: service areas, local rules, real addresses and local examples.
  • Integration or comparison pages: each with specific features, limits and setup steps.
  • Directories: listings with reviews, hours and verified contact details.

In each case, the template organises useful data. The data, not the template, gives the page its value.

Where it fails

It fails when the only difference between pages is a city or keyword name. For example, 500 pages that each say "We offer the best plumbing in [city]" with identical paragraphs add nothing. Google's spam policies describe this as scaled content abuse. Meanwhile, AI assistants skip such pages because they contain no specific facts to quote.

How to add unique value to each page

  1. Start with the dataset. List the fields that differ for each page. If there are only one or two, the page set is probably too thin.
  2. Add local or specific facts. For city pages, include real areas served, local needs and examples.
  3. Write variable sections. Use conditional blocks so pages with different traits show different text.
  4. Include visuals with data. Charts or tables built from each page's own figures.
  5. Add human review. An editor checks a sample of every batch before it goes live.
  6. Link pages logically. Connect each page to its hub and to close neighbours.

Launch in small batches

Start with 10 to 50 pages. Then check indexing in Search Console, engagement in analytics and rankings for a sample. Expand only when the first batch performs. Programmatic SEO and AI search

AI tools quote specific, verifiable facts. So a programmatic page with a real price range, a real timetable or a real feature list can earn citations. In contrast, a templated page full of general claims gives them nothing. That makes data quality the key factor for programmatic pages in AI search too. Technical checks for template pages

  • Unique title, description and H1 for each page.
  • Self-referencing canonical tags.
  • Pages included in the XML sitemap.
  • Internal links from hub pages so nothing is orphaned.
  • Fast, server-rendered HTML, as in JavaScript SEO for AI.

Should you prune old programmatic pages?

If a large page set gets little traffic and few indexed URLs, consider pruning. Merge similar pages, improve the best ones and remove the rest with redirects where it makes sense. A smaller set of strong pages often outperforms a large set of thin ones.
