Image SEO and video SEO help your visual content appear in Google Images, video results, Discover and AI answers. The essentials are descriptive file names and alt text, modern formats at sensible sizes, pages that give each image or video clear context, and structured data where it applies. Done well, image SEO also speeds up your pages and makes them more accessible.

Image SEO basics

  • File names: use short descriptive names, such as kolkata-office-team.webp, not IMG_4821.jpg.
  • Alt text: describe what the image shows in the context of the page, in a short phrase.
  • Format: use WebP or AVIF for photos and SVG for logos and simple graphics.
  • Size: resize images to the largest size they display at, then compress them.
  • Dimensions: set width and height attributes to prevent layout shifts.
  • Lazy loading: add loading="lazy" to images below the fold, but not to the main image.

How to write good alt text

Alt text serves people who use screen readers first, and search engines second. So describe what matters about the image for this page. For example, "Team reviewing a website audit on a laptop" beats "SEO SEO agency best SEO". Skip alt text on purely decorative images by using an empty alt="". Context matters

Search engines understand images partly through the text around them. Place images near the paragraph they illustrate, and use captions where they add meaning. In addition, use original photos and graphics where you can; unique images help your page stand out, while stock photos appear on thousands of sites.

Video SEO basics

  1. Give each video its own page or a clear section on a relevant page.
  2. Write a clear title and description that match what people search for.
  3. Add a transcript below the video, so the content is readable as text.
  4. Use chapters on YouTube or key moments markup, so search can link to parts of the video.
  5. Add VideoObject structured data with name, description, thumbnail and upload date.
  6. Provide a good thumbnail that shows the topic clearly.

Google's guide to video best practices lists every requirement.

YouTube and your site

YouTube is a search engine of its own, and AI tools often cite videos for how-to questions. So publish on YouTube, then embed the video on the matching page of your site with a transcript and summary. That way, both the video and the page can rank and support each other. Images, video and AI answers

AI tools mostly read text, so transcripts, captions and alt text are how they understand your visuals. Charts should come with a written summary of the key numbers. Likewise, infographics need the same facts in HTML text. Otherwise, AI tools and many crawlers miss the content entirely.

Large images are the most common cause of slow Largest Contentful Paint. Therefore, serve the hero image in a modern format, at the right size, and preload it if it is the main element. Our Core Web Vitals fix guide and the existing guide to website speed optimization cover the detail.

Image SEO checklist

  • Descriptive file names and alt text on every meaningful image.
  • WebP, AVIF or SVG formats at the right size.
  • Width and height set on all images.
  • Transcripts and VideoObject markup for videos.
  • An image sitemap or images listed in your XML sitemap for large galleries.
