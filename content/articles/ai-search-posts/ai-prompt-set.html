An AI prompt set is a fixed list of buyer questions that you run in AI assistants on a schedule to measure your brand's visibility. A good set has about 30 prompts spread across five intent types, stays frozen for at least six months, and records the same fields each time: mentioned or not, cited or not, how you are described and who else appears.

Why you need a frozen prompt set

AI answers change from run to run, between tools and over time. If you also change the questions each month, you cannot tell whether visibility moved because of your work or because you asked something new. So freeze the list. Then any change in results reflects the market or your efforts, not the test.

The five intent types

BrandWhat does Openink Hub do, and is it reliable?4
CostHow much does monthly SEO cost in India?6

Adjust the split for your business, but keep all five types. Brand prompts show how AI tools describe you; discovery prompts show whether they recommend you unprompted.

How to write good prompts

  • Use the buyer's words, taken from sales calls and search queries.
  • Include a location or segment where it matters, such as "for a small shop".
  • Avoid naming your brand except in the brand group.
  • Keep each prompt to one question.
  • Write them as a person would type or say them, not as keywords.

How to freeze and run the set

  1. Save the 30 prompts in a sheet with an ID for each.
  2. Pick the tools to test, for example ChatGPT, Gemini, Perplexity and Copilot.
  3. Use a logged-out or clean session where possible, so personal history does not skew results.
  4. Run each prompt three times per tool, since answers vary.
  5. Log results on the same days each month.

What to record each month

  • Mentioned: did the answer name your brand?
  • Cited: did it link to your site?
  • Position: first, middle or last among brands named.
  • Description: was it accurate?
  • Competitors: which rivals appeared?
  • Sources: which sites did the answer cite?

From this, calculate your mention rate: prompts where you appear divided by total prompt runs. That single figure works well in a monthly report, as shown in our AI visibility dashboard template.

When to change the AI prompt set

Review the set every six to twelve months, or when you launch a new service. When you change it, keep most prompts and add new ones in a separate group. That way the trend line stays intact.

Tools or spreadsheet?

A spreadsheet works fine for 30 prompts and four tools. Paid tracking tools help when you need many markets, daily runs or charts; our comparison of AI search tracking tools covers the options. Either way, the frozen AI prompt set is what makes the numbers meaningful.
