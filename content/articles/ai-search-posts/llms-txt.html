llms.txt is a proposed plain-text file, placed at the root of a website, that gives large language models a short summary of the site and links to its most useful pages. It was suggested in 2024 as a way to help AI tools find clean, relevant content. However, no major search engine has confirmed that it uses the file for ranking or citations, so treat it as a small, low-cost extra rather than a strategy.

What llms.txt is meant to do

Web pages carry menus, ads, scripts and footers that make them harder for a model to read. The idea is to offer a tidy map instead: a title, a one-paragraph summary and grouped lists of links to key pages, written in Markdown. The proposal is documented at llmstxt.org.

Some versions also suggest an llms-full.txt file that includes the full text of key pages. That mainly suits documentation sites.

Does llms.txt help?

Here is the honest answer. Google has not said it reads the file for Search or AI Overviews. OpenAI, Anthropic and Perplexity have not published rules that use it for citations either. Some AI developer tools and coding assistants do read it when pointed at a docs site.

So the file may help in narrow cases, such as developer documentation. For a typical business site, it is unlikely to change AI visibility on its own. Our article on AI search myths covers this and similar claims.

In short, robots.txt controls access, while the newer file only suggests what to read. For crawler rules, see our guide to AI crawlers in robots.txt.

How to create an llms.txt file

  1. Create a text file named llms.txt.
  2. Start with a heading line: # Your Brand Name.
  3. Add a one-paragraph summary as a quote, starting with >.
  4. Add sections such as ## Services and ## Guides.
  5. Under each, list links as - [Page title](https://yourdomain.com/page/): one-line description.
  6. Upload it to your site root so it loads from the root of your domain.
  7. Update it when you add or remove key pages.

A short example

# Example Agency
> Example Agency offers SEO and web design for small businesses in Kolkata.

## Services
- [SEO services](https://www.example.com/seo/): monthly SEO plans
- [Web design](https://www.example.com/web-design/): business websites

## Guides
- [What is local SEO](https://www.example.com/local-seo/): beginner guide

Who should add one

Software companies, API providers and businesses with large help centres gain the most, because developers often point coding assistants at their docs. Publishers with deep archives may also find it useful as a curated reading list. For a local shop or a small service firm, it is a ten-minute task with an uncertain payoff, so do it after the basics rather than before. Either way, keep the list short and focused on pages you would want a new customer to read first.

What matters more than llms.txt

Clean HTML with real text, clear headings, fast pages, correct robots rules and consistent brand facts all matter far more. Then add answer-first writing on key pages. These steps help Google, Bing and every AI assistant, whether they read the file or not.
