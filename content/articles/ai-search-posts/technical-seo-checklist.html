This technical SEO checklist for AI search covers the checks that let Google, Bing and AI crawlers fetch, render, understand and trust your pages: crawl access, indexing, rendering, speed, structured data, security and AI bot rules. If these basics fail, no content or link work can fully pay off, so run through the list before anything else.

1. Crawling

  • robots.txt allows important pages and lists your XML sitemap.
  • Also, no key pages sit behind logins, forms or blocked scripts.
  • Internal links use real <a href> anchors that crawlers can follow.
  • Server logs or Search Console crawl stats show regular Googlebot visits.
  • No long redirect chains; instead, each old URL redirects once to its final page.

2. Indexing

  • Important pages return a 200 status and have no stray noindex tags.
  • Then each page has a self-referencing canonical, or a canonical to the main version.
  • The XML sitemap lists only indexable, canonical URLs.
  • Search Console's Pages report shows few "Crawled, currently not indexed" URLs.
  • Finally, duplicate versions (http, www, trailing slash) redirect to one form.

3. Rendering

  • Main text, links and metadata appear in the raw HTML.
  • Any JavaScript-loaded content also has a server-rendered or static fallback.
  • URL Inspection in Search Console shows the full rendered page.

4. Speed and page experience

  • Core Web Vitals pass at the 75th percentile: LCP within 2.5 s, INP within 200 ms, CLS below 0.1.
  • Images use modern formats with width and height set.
  • Pages work well on mobile, so there are no intrusive pop-ups.

See our Core Web Vitals fix guide for detailed fixes.

5. Structured data

  • Organization schema on the home page, with logo and sameAs links.
  • Article or BlogPosting on posts, with author and dates.
  • BreadcrumbList on deep pages.
  • In addition, all markup matches visible content and passes validation.

Our schema markup guide includes examples.

6. Security

  • HTTPS everywhere, with HSTS enabled.
  • No mixed content warnings.
  • Security headers such as a Content Security Policy; see security headers and SEO.
  • Software and plugins kept up to date, since old versions invite attacks.

7. AI crawler access

  • robots.txt rules set on purpose for OAI-SearchBot, GPTBot, ClaudeBot, PerplexityBot and Google-Extended.
  • Meanwhile, CDN or firewall bot settings do not block the AI search bots you want.
  • Key facts such as prices and services appear as text instead of images.

Our guide to AI crawlers in robots.txt includes a sample policy.

8. International and accessibility

  • hreflang tags in place, once you serve several languages or countries.
  • Headings in order, labelled forms and keyboard access; see our accessibility SEO checklist.

How to use this technical SEO checklist

First, run a crawl with a tool such as Screaming Frog or Sitebulb, then check Search Console's Pages, Core Web Vitals and Crawl stats reports. Next, mark each item pass or fail and fix failures in order of impact: crawling and indexing first, then rendering, then speed. Finally, repeat the check after every redesign or migration. Google's Search Essentials lists its baseline technical requirements.
