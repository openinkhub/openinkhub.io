Core Web Vitals are Google's three page experience metrics: Largest Contentful Paint (LCP) for loading, Interaction to Next Paint (INP) for responsiveness, and Cumulative Layout Shift (CLS) for visual stability. A page passes when, at the 75th percentile of real visits, LCP is within 2.5 seconds, INP is within 200 milliseconds and CLS is below 0.1. This fix guide shows how to find the cause of a poor score and the fixes that work most often.

INP replaced First Input Delay (FID) as a Core Web Vital in March 2024. Google's Web Vitals overview explains each metric.

Find the problem first

  1. Open Search Console's Core Web Vitals report to see which URL groups fail.
  2. Run a failing URL in PageSpeed Insights and check the field data at the top.
  3. Scroll to the diagnostics to see which element or script causes the issue.
  4. Reproduce it in Chrome DevTools using the Performance panel.

Fix templates, not single pages, because one template often controls hundreds of URLs.

Fixing LCP

LCP measures when the largest visible element, often a hero image or heading, finishes rendering. Common fixes:

  • Serve the hero image in WebP or AVIF at the right size.
  • Preload the LCP image and avoid lazy-loading it.
  • Reduce server response time with caching or a CDN.
  • Remove render-blocking CSS and JavaScript from the head.
  • Avoid sliders or carousels as the first element.

Fixing INP

INP measures how quickly the page responds after a click, tap or key press. So the usual cause is heavy JavaScript on the main thread. Common fixes:

  • Break long tasks into smaller chunks.
  • Remove unused scripts and third-party tags.
  • Delay non-essential scripts until after interaction.
  • Avoid large DOM updates in response to a single input.

Fixing CLS

CLS measures unexpected movement of content while the page loads. Common fixes:

  • Set width and height on all images and video embeds.
  • Reserve space for ads, banners and cookie notices.
  • Load web fonts with font-display: swap and matching fallback sizes.
  • Avoid inserting content above existing content after load.

Do Core Web Vitals affect rankings?

They are part of Google's page experience signals. Relevance and quality still matter far more, but when pages are similar, better experience can tip the balance. In addition, faster pages convert better and keep visitors longer, which helps every channel.

Core Web Vitals and AI crawlers

AI crawlers do not measure Core Web Vitals, yet slow servers and heavy pages can cause timeouts or partial fetches. A fast, light page is more reliably read by every bot. See our guide to JavaScript SEO for AI for the rendering side.

Track progress

Field data in Search Console updates over a 28-day window, so changes take a few weeks to show. Use PageSpeed Insights lab data for quick checks, then confirm with field data later.
